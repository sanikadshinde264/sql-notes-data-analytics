# 📚 SQL (Structured Query Language)

SQL (Structured Query Language) is a standard programming language used to communicate with relational databases. It allows us to store, retrieve, update, delete, and manage data efficiently.

## 📌 SQL

SQL is used for:

* Storing data
* Retrieving data
* Updating records
* Deleting records
* Analyzing business data
* Generating reports
* Managing large amounts of information

## 📊 Data

Data is a collection of raw facts and figures that can be stored, processed, and analyzed to generate meaningful information.

Examples of data include:

* Numbers
* Text
* Images
* Videos

## 🗄️ Database

A database is a collection of data that can be easily accessed and managed digitally.

**Example: Instagram**

Instagram stores information such as:

* User profiles
* Followers
* Posts
* Likes
* Comments

## 🎯 Purpose of Storing Data in a Database

* Fast Searching
* Better Security
* Backup and Recovery
* Multi-User Access
* Easy Updates

## ⚙️ Database Management System (DBMS)

DBMS stands for **Database Management System**.

A DBMS is software that allows users to create, manage, update, and retrieve data from databases.

**Examples:**

* MySQL
* Oracle Database
* Microsoft SQL Server
* PostgreSQL

## 📋 Table Structure

Data in a relational database is organized in the form of tables.

A table contains:

* **Columns / Fields / Attributes**
* **Rows / Tuples / Records**
* **Primary Key**
* **Column Names**

## 🔗 RDBMS

RDBMS stands for **Relational Database Management System**.

An RDBMS is a type of DBMS that stores data in related tables and uses relationships between those tables to reduce data redundancy and improve data integrity.

### Example

**Customers**

* CustomerID
* Name
* Email
* Phone

**Orders**

* OrderID
* CustomerID
* OrderDate
* Amount

The `CustomerID` creates a relationship between the Customers and Orders tables.

## 🏢 Popular RDBMS Software

* **MySQL** – Open-source relational database management system
* **PostgreSQL** – Open-source and powerful RDBMS
* **Oracle Database** – Enterprise-grade database system
* **Microsoft SQL Server** – Relational database system by Microsoft

## 🌐 SQL and Different RDBMS

SQL follows international standards such as **ANSI SQL / ISO SQL**.

Basic SQL commands are generally similar across different relational database systems. However, some advanced syntax and features may differ between MySQL, PostgreSQL, Oracle, and SQL Server.

For beginners, it is recommended to learn SQL using one RDBMS such as **MySQL or PostgreSQL**.
